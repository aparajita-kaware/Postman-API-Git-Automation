# Postman & Newman REST API Automation Portfolio

End-to-end automated REST API test frameworks for **ReqRes** and **Restful-Booker**, featuring CSV data-driven execution, dynamic variable chaining (`userId`, `authToken`, `bookingid`), negative boundary validation, and automated CLI/HTML reporting via **Newman**.
